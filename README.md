# Lost-Child-Identification-System
A web-based system for reporting, tracking, and managing missing child information with role-based access control.
## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js

## Features

- Missing child reporting system
- Role-based access control (Admin and User)
- Add, update, and delete child records
- Search functionality for quick identification
- Google Maps location support
- Secure data management
- User-friendly interface

## Project Objective

The main objective of this project is to assist in the quick reporting and identification of missing children through a centralized online platform. It helps improve accessibility to child information and supports efficient record management.

## User Roles

### Admin
- Add child records
- Update child information
- Delete records
- Manage system data

### User
- View child information
- Search records
- Access location details

## Future Enhancements

- Image recognition for child identification
- Real-time notifications
- Mobile application support
